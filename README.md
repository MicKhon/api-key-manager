# Сервис управления API-ключами

Автор: Михаил Хонинев, группа ЭФБО-10-24  
Тема проекта: 219

## Назначение

Сервис позволяет разработчикам выпускать, проверять и отзывать API-ключи
для своих приложений, а также ограничивать доступ к операциям с помощью
разрешений.

## Целевая аудитория

Разработчики и администраторы приложений, которым нужно безопасно
выдавать доступ к API: выпускать ключи, следить за сроком действия
и отзывать скомпрометированные ключи.

## Предметная область

Управление программным доступом к API. Пользователь регистрирует
приложение, для приложения выпускается ключ, у ключа есть срок действия
и набор разрешений. По ключу сервис понимает, кто выполняет запрос
и какие действия ему разрешены.

## Основные сущности

- пользователь
- приложение
- ключ
- разрешение

## Основные функции

- проверка статуса API-ключа (активен или отозван)
- проверка срока действия ключа
- проверка разрешения пользователя на действие
- маскирование ключа при выводе

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
