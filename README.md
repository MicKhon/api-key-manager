# Сервис управления API-ключами

Автор: Михаил Хонинев, группа ЭФБО-10-24  
Тема проекта: 219

Консольное приложение для учёта пользователей, приложений,
разрешений и API-ключей.

Этап практической работы № 2 завершён: сущности разнесены по пакетам,
данные хранятся в JSON, меню и pytest покрывают пользователя,
приложение, разрешение и ключ. Классы не используются — это этап ПР3.

## Возможности

- пользователи: просмотр, поиск, добавление;
- приложения: просмотр, поиск, добавление;
- разрешения: просмотр справочника;
- ключи: просмотр, выпуск, отзыв, проверка статуса и прав, статистика.

## Основные сущности

Каждая сущность — отдельная папка с модулем и тестами:

- пользователь — `entities/users/` / `tests/users/`
- приложение — `entities/applications/` / `tests/applications/`
- разрешение — `entities/permissions/` / `tests/permissions/`
- ключ — `entities/keys/` / `tests/keys/`

## Структура проекта

```
api-key-manager/
├── main.py
├── entities/
│   ├── users/
│   ├── applications/
│   ├── permissions/
│   └── keys/
├── storage/
├── utils/
├── data/
└── tests/
    ├── users/
    ├── applications/
    ├── permissions/
    └── keys/
```

- `main.py` — точка запуска и меню;
- `entities/` — модули сущностей;
- `storage/` — сохранение и загрузка JSON;
- `utils/` — ввод данных и генерация ключа;
- `data/` — JSON-файлы сущностей;
- `tests/` — тесты, разложенные по сущностям.

## Формат данных

Пользователи — `data/users.json`:

```json
[{"id": 1, "name": "Михаил Хонинев"}]
```

Приложения — `data/applications.json`:

```json
[{"id": 1, "name": "Платежный шлюз", "user_id": 1}]
```

Разрешения — `data/permissions.json`:

```json
[{"id": 2, "code": "write", "title": "Запись"}]
```

Ключи — `data/keys.json`:

```json
[
    {
        "id": 1,
        "app_id": 1,
        "value": "ak_live_9f3a2c1b8e7d",
        "is_active": true,
        "permission": "write",
        "expiry_date": "2026-12-31"
    }
]
```
