# Сервис управления API-ключами

Автор: Михаил Хонинев, группа ЭФБО-10-24  
Тема проекта: 219

Консольное приложение для учёта пользователей, приложений,
разрешений и API-ключей.

Этап практической работы № 3 завершён: сущности предметной области
представлены классами `User`, `Application`, `Permission` и `ApiKey`.
Коллекции содержат объекты, JSON по-прежнему хранит только данные.

## Возможности

- пользователи: просмотр, поиск, добавление;
- приложения: просмотр, поиск, добавление;
- разрешения: просмотр справочника;
- ключи: просмотр, выпуск, отзыв, проверка статуса и прав, статистика.

## Основные классы

Каждая сущность — отдельный пакет с классом и функциями коллекции:

### User — пользователь

Атрибуты: `id`, `name`.  
Методы: `__init__`, `__str__`, `from_data()`, `to_dict()`.

### Application — приложение

Атрибуты: `id`, `name`, `user` (объект `User`).  
Методы: `__init__`, `__str__`, `from_data()`, `belongs_to()`, `to_dict()`.

### Permission — разрешение

Атрибуты: `id`, `code`, `title`.  
Методы: `__init__`, `__str__`, `from_data()`, `covers()`,
`validate_code()`, `to_dict()`.

### ApiKey — API-ключ

Атрибуты: `id`, `application` (объект `Application`), `value`,
`is_active`, `permission` (объект `Permission`), `expiry_date`.  
Методы: `__init__`, `__str__`, `from_data()`, `revoke()`, `is_usable()`,
`mask_value()`, свойство `status`, `to_dict()`.

Все четыре класса наследуют `Entity` с общим идентификатором.

## Взаимодействие объектов

Пользователь владеет приложением: `application.user` — объект `User`.
Ключ выпускается для приложения и несёт разрешение:
`key.application` и `key.permission` — связанные объекты, а не
идентификаторы. Через ключ можно получить владельца приложения:
`key.application.user`.

## Формат данных

JSON-файлы не содержат внутреннюю структуру Python-объектов.
Связи хранятся идентификаторами.

Пользователи — `data/users.json`:

```json
[{"id": 1, "name": "Михаил Хонинев"}]
```

Приложения — `data/applications.json`:

```json
[{"id": 1, "name": "Платежный шлюз", "user_id": 1}]
```

Разрешения — `data/permissions.json`:

```json
[{"id": 2, "code": "write", "title": "Запись"}]
```

Ключи — `data/keys.json`:

```json
[
    {
        "id": 1,
        "app_id": 1,
        "value": "ak_live_9f3a2c1b8e7d",
        "is_active": true,
        "permission": "write",
        "expiry_date": "2026-12-31"
    }
]
```

При загрузке идентификаторы превращаются в ссылки на объекты.
При сохранении объекты снова записываются как идентификаторы.

отзыв ключа, поиск и сортировку коллекций.
