# Сервис управления API-ключами

Автор: Михаил Хонинев, группа ЭФБО-10-24  
Тема проекта: 219

Консольное приложение для учёта приложений и управления API-ключами:
выпуск, проверка статуса, проверка разрешений и отзыв ключей.

## Возможности

- просмотр и поиск приложений;
- добавление приложений;
- просмотр ключей с маскированием значения;
- проверка статуса и срока действия ключа;
- проверка разрешения ключа;
- выпуск нового ключа;
- отзыв ключа;
- статистика по ключам.

## Основные сущности

- пользователь
- приложение
- ключ
- разрешение

## Структура проекта

- `main.py` — точка запуска и меню;
- `applications.py` — работа с приложениями;
- `keys.py` — работа с API-ключами (включая функции из ПР1);
- `storage.py` — сохранение и загрузка JSON;
- `utils.py` — ввод данных и генерация ключа;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Формат данных

Приложения хранятся в `data/applications.json`:

```json
[
    {"id": 1, "name": "Платежный шлюз", "owner": "Михаил Хонинев"}
]
```

Ключи хранятся в `data/keys.json`:

```json
[
    {
        "id": 1,
        "app_id": 1,
        "value": "ak_live_9f3a2c1b8e7d",
        "is_active": true,
        "permission": "write",
        "expiry_date": "2026-12-31"
    }
]
```
